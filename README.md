# 世界大战 · 全球战争档案
### THE WORLD AT WAR — AN INTERACTIVE ARCHIVE, 1931–1945

一个以第二次世界大战为主题的完整交互式网站：可拖拽旋转的 **3D 地球作战室**、可旋转的 **3D 装备解剖台**、逐年变化的 **全球态势图**，以及为每件装备、每位人物、每个国家制作的 **六维替身面板雷达图**。

---

## 打开方式

### 方式一：本地服务器（推荐）

双击 `start-site.cmd`，或在项目目录运行：

```powershell
python -m http.server 8788 --bind 127.0.0.1
```

然后访问：

**http://127.0.0.1:8788/**

### 方式二：直接打开

双击 `index.html` 也可以浏览绝大部分内容。3D 纹理、部分图片与 Canvas 在 `file://` 下受浏览器本地文件策略影响，建议使用本地服务器获得完整体验。

无需构建、无需安装依赖、无需联网。Three.js、字体与图片都已放在本地。

## 交互指南

### 3D 地球

- **拖拽**：旋转地球
- **滚轮**：缩放
- **点击彩色光点**：打开对应战役或事件档案
- **右侧控制**：放大、缩小、复位、暂停自动旋转
- **自动巡航**：按顺序飞往关键战场
- **HUD 关键节点**：点击斯大林格勒、诺曼底、中途岛、柏林迅速打开档案

### 3D 装备解剖台

- **拖拽**：旋转 T-34、虎式、喷火、大和号
- **滚轮**：缩放
- **蓝图模式**：切换为线框结构
- **打开装备档案**：进入完整装备页

### 雷达图 / 替身面板

每件装备、每位人物、每个国家都有六维雷达图与 A—E 等级条。

- 装备：火力、防护、机动、可靠、产量、影响
- 人物：战略、战术、指挥、动员、影响、争议
- 国家：工业、军力、动员、科技、韧性、外交
- 战役：规模、惨烈、战略影响、转折性、技术、持续时间

> 雷达图是**编辑性比较可视化**，不是精确的性能、能力或道德评分。人物面板中的“争议”代表历史评价分歧或战争责任权重，不是负面能力，也不为暴行开脱。

### 检索与筛选

- 顶部搜索按钮或 `Ctrl / ⌘ + K`：全文检索 76 份档案
- `↑` `↓` 选择结果，`Enter` 打开
- 战役按战区筛选；装备按类别筛选；人物按阵营/身份筛选
- 弹窗：`Esc` 关闭；关闭后回到原位置

### 深链接

`?file=equipment-t34`、`?file=person-zhukov`、`?file=battle-stalingrad`、`?file=country-china`、`?file=event-nanjing` 等可以直接打开档案。

## 技术与文件结构

```text
ww2-atlas/
├─ index.html
├─ start-site.cmd
├─ css/
│  └─ style.css
├─ js/
│  ├─ data.core.js        # 年表、态势、资料来源
│  ├─ data.battles.js     # 18 场战役
│  ├─ data.equipment.js   # 21 件装备
│  ├─ data.people.js      # 18 位人物
│  ├─ data.countries.js   # 8 个国家
│  ├─ data.events.js      # 11 个事件
│  ├─ world-dots.js       # Natural Earth 110m 生成的点阵地图
│  ├─ credits.js          # 图片出处
│  ├─ globe.js            # Three.js 3D 地球
│  ├─ exhibit.js          # Three.js 3D 装备模型
│  ├─ situation.js        # Canvas 2D 态势点阵图
│  └─ app.js              # 渲染、雷达图、检索、档案弹窗、交互
├─ assets/
│  ├─ vendor/             # Three.js r128 + postprocessing
│  ├─ fonts/              # Bebas Neue / Barlow Condensed / Special Elite
│  ├─ images/             # 历史影像、地球纹理
│  └─ favicon.svg
└─ tools/                 # 影像抓取、点阵地图、作品数据脚本
```

- 无框架、无构建步骤、无追踪、无第三方运行时依赖。
- 3D：Three.js r128，WebGL；移动端自动降低像素比。
- 雷达图：内联 SVG，服务端无需生成。
- 态势图：Canvas 2D 点阵地图，Natural Earth 110m 国界栅格化后按年份着色。
- 尊重 `prefers-reduced-motion`；支持键盘与焦点管理。
- 图片懒加载；图片缺失时显示程序生成的“ARCHIVE PLATE”档案图版，而不是破图。

## 影像与版权

- 历史照片来自 **Wikimedia Commons** 等公共历史档案；每份档案底部显示图片来源与许可信息。
- 少量图片在下载/授权不确定时使用程序生成的档案图版（ARCHIVE PLATE），不冒充历史照片。
- 旗帜为示意绘制：德国使用铁十字而非纳粹卐字，日本使用日章旗而非旭日旗，避免美化军国主义符号。
- 本项目为**历史科普与视觉叙事**，不是军事建议、学术论文或官方史。伤亡数字、装备参数与人物评价存在统计口径与史学争议。
- 若图片版权标注仍有遗漏，请以 Wikimedia Commons 文件页为准并联系更正。
